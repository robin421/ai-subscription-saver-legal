AI Subscription Saver – Privacy Policy

Effective Date: November 9, 2026 | Last Updated: November 9, 2026

This Privacy Policy explains how AI Subscription Saver – Passwords, API Keys & AI Prices ("AI Subscription Saver", "the extension", "we", "us", or "our", Extension ID: fabljnimgpfjpblfbmmalegcoibcimig) handles user data. Your privacy, security, and digital sovereignty are our highest priorities.

1. Summary & Core Principles

  • No External Data Collection: We do not collect, transmit, store, track, or sell your personal data, credentials, or browsing history.
  • Client-Side Zero-Knowledge Architecture: All passwords, API keys, logins, and subscription records are encrypted directly on your device using PBKDF2-SHA256 (600,000 iterations) and AES-256-GCM. Your master password never leaves your browser.
  • No Backend Servers: AI Subscription Saver does not operate backend servers for user accounts, vault synchronization, or behavioral tracking.
  • No Ads or Third-Party Tracking SDKs: The extension contains zero advertisements, telemetry, or analytics trackers.

2. Data Stored Locally on Your Device

All sensitive information is stored exclusively in your local browser storage (IndexedDB and chrome.storage.local), secured by client-side cryptography:

  • Encrypted Vault Records: Website credentials, usernames, passwords, API keys, URLs, and private notes. Decryption only happens in temporary memory while the vault is explicitly unlocked by your master password.
  • Subscription Tracking Data: Service names, renewal dates, billing cycles, and cost figures saved by the user for subscription budgeting and renewal alerts.
  • Public Pricing Cache: Read-only, publicly available AI service pricing tiers retrieved from AISubDeal to show price hints offline without repeatedly querying the web.
  • Extension Preferences: Local settings such as auto-lock timer duration and theme preference.

3. Chrome Permissions & Strict Usage Justifications

AI Subscription Saver adheres strictly to Google's principle of least privilege. Each declared permission serves an indispensable, user-facing function:

  • storage: Required to persist encrypted vault entries, user settings, subscription reminder dates, and public pricing cache locally on the device.
  • alarms: Required to power background timers for vault auto-lock security, periodic price cache refreshes, and the automated clipboard security wiper.
  • activeTab: Required only when the user explicitly triggers credential autofill (via the popup action or keyboard shortcut Alt+Shift+L). It temporarily accesses the active tab to identify login/password fields. It does not monitor or access tabs passively in the background.
  • scripting: Required to execute the isolated credential autofill helper script into the current active page only upon direct user request.
  • idle: Required to detect operating system lock or inactivity to automatically lock the encrypted vault, protecting credentials if the computer is unattended.
  • offscreen: Required to host a temporary, isolated offscreen document that automatically overwrites and purges copied passwords and API keys from your system clipboard after 30 seconds.
  • notifications (optional): Requested only if the user enables subscription renewal alerts, delivering local desktop notifications before renewals occur.
  • https://www.aisubdeal.com/* (optional host permission): Enables the user to fetch optional public price comparison tables. Requests are completely anonymous, sent via GET without user identifiers, vault data, or authentication tokens.

4. Chrome Web Store User Data Policy Compliance

In full compliance with the Chrome Web Store Developer Program Policies:

  • We do not sell, rent, lease, or transfer user data to third parties.
  • We do not use or transfer user data for purposes unrelated to the extension's core single purpose: an encrypted vault for logins/API keys with autofill and AI subscription price comparisons.
  • We do not use or transfer user data to determine creditworthiness or for lending purposes.
  • We do not use remote code; all application code is statically bundled inside the signed extension package.

5. Data Retention, Backup & Deletion

Because all data resides strictly on your local machine:

  • You may export encrypted, password-protected JSON backups at any time.
  • You can delete individual vault entries or purge the entire vault inside the extension settings.
  • Uninstalling the extension from Google Chrome immediately and permanently removes all stored data from your device.

6. Children's Privacy

AI Subscription Saver is a general productivity tool and does not knowingly collect or target information from children under the age of 13.
